# 基于稀疏可信测点与物理约束的芯片温度场重构——面向片上热自监测

> 竞赛叙事主文档(M4 初稿)。所有数字均来自本仓库的实测数据或文献,图表路径指向仓库内可复现的产物。

## 摘要

芯片/板卡的热管理需要**稠密且准确**的温度场,但现实中两类测量手段各缺一半:红外热像仪给出稠密图像却受发射率系统偏差污染(且封闭机箱内无光学通路,无法部署);接触式/片上传感器读数准确却极其稀疏。本项目训练一个**物理约束的注意力算子网络**(约 1.2M 参数),从任意 K 个稀疏可信测点重构整板温度场:先在有限差分求解器生成的大规模随机场景上进行**域随机化预训练**,再用红外+黑胶带标定实验对**具体板卡微调**,即"通用物理先验的按板标定"。网络足够小,可部署在被监测设备自身上,由设备用自己的传感器实时重构自己的全场温度——热自监测。

## 1. 背景:为什么这是一个真实且紧迫的问题

1. **算力功耗密度爆炸。** AI 加速器单芯片功耗从 400 W(2022)→ 700 W(2023)→ 约 1000–1200 W(Blackwell 时代);机柜功率密度正走向 250–900 kW(2026–27 预测)。热点(hotspot)直接驱动两件事:降频(性能损失)与可靠性失效(电迁移、焊点疲劳)。
2. **动态热管理(DTM)依赖稠密温度场。** 片上温度传感器因面积/成本只有寥寥数个;仅凭稀疏读数,DTM 要么高估热点(白白降频)、要么低估(可靠性风险)。文献中"全芯片温度场估计"已是工业问题:CNN 方法用 4 个传感器即可将 8 核设计的全片温度图恢复到 ~1 °C;GAN 方法在 Intel i7 实测上达到 ~1.3 °C 平均误差。
3. **红外热像不是答案,而是问题的一部分(本项目的物理内核)。** PCB 表面材料发射率横跨 ~0.05(裸金属/屏蔽罩)到 ~0.95(阻焊层、环氧封装)。**我们自己的数据直接展示了这一失效**:满载时 USB/HDMI/以太网屏蔽罩在 50–60 °C 的板面中"显示"接近室温(见 `reports/qc/physics_canonical.png`)。定量地,发射率设定 0.93 对 ε=0.95 黑胶带点的系统偏差为 +0.17 °C(33 °C 处)至 +0.92 °C(79 °C 处),且随温度上升——对低发射率表面误差可达数十摄氏度。此外,部署场景(封闭服务器/嵌入式设备内部)根本没有红外光学通路。
4. **结论:问题定式。** 从 K 个稀疏但可信的测点重构稠密温度场,以热传导方程为先验正则化这一不适定逆问题。这正是文献中的 **TFR-HSS**(heat-source systems 温度场重构)问题类,有公开基准数据集 TFRD,其动机原文即"电子设备的实时健康监测"。

## 2. 方法

### 2.1 网络:集合不变的注意力算子

- SensorEncoder:每个测点 (x, y, θ) 经随机傅里叶特征编码 → d_model=128;
- 传感器集合自注意力(2 层,置换不变,K 可变、由 padding mask 处理);
- 查询点 (x, y) 经交叉注意力(3 层)读取传感器集合 → MLP 头输出 θ(x, y);
- 一次训练,任意测点数/位置/查询分辨率的推理("离散化无关")。

### 2.2 无量纲化契约(sim-to-real 的关键)

- 过余温度 **θ = (T − T_amb) / ΔT_s**,ΔT_s 取测点最大过余温度(设下限)——推理时仅凭输入即可计算,消除热像仪逐帧偏移;
- 坐标以板长边归一;板卡域为 [0, a]×[0, 1](Pi 4B:a = 103/157 ≈ 0.656,约 0.543 mm/px);
- 稳态方程坍缩为 **∇̃²θ − ĥθ + Q̂ = 0**,唯一物理参数 **ĥ = hL²/(k_eff·d)**;
- 线性 PDE + 齐次边界 ⇒ 幅值尺度精确约去:对"更严酷工况"的外推鲁棒性**由构造保证**(并经实验验证)。

### 2.3 域随机化预训练 → 按板微调

- 预训练:4096 个随机场景(纵横比 0.5–1、ĥ ∈ log-U[0.3, 30](范围由第 4 节实测界定)、Dirichlet/Robin 边界、1–5 个旋转各向异性高斯/平滑矩形热源),数据损失 + 自动微分 PDE 残差损失(λ 渐升至 1e-3);传感器课程:随机 K∈[4,16](80%)+ 实测胶带布局抖动(20%),叠加与实测重复性一致的噪声;
- 微调:以实测像素(可信掩膜加权 1/σ²)监督,胶带测点**留作验证从不参与训练**;真实板 PDE 残差只在无源区域施加,**ĥ 作为可学习参数**并与实测约束交叉验证;50% 新鲜合成数据回放防遗忘;
- 评估纪律:半载+待机微调,**满载工况只作为最终测试触碰一次**(外推声明);与 RBF/双三次/高斯过程/逐场景 PINN 基线在完全相同的测点集上对比;λ=0 孪生网络作为物理消融。

## 3. 实验(已完成部分:M1–M2)

**装置**:Raspberry Pi 4B(85×56 mm),HIKMICRO 红外热像仪(192×256,~6.3 s/帧,ε 设 0.93,距离 0.1 m),黑胶带(ε≈0.95)贴于选定元件。6 个工况共 336 帧:断电/待机/满载(120 帧)/满载冷却/半载(120 帧)/半载冷却。

**数据管线**(`scripts/ingest_real_data.py`):逐帧解析并与热像仪自带统计块交叉校验(**336/336 通过**);以积分图能量准则定位 157×103 板窗(整个负载会话共享同一窗口,逐工况检测偏差 ≤2 px);断电工况(2 小时后重新摆放)经梯度 ZNCC 旋转配准确认 180° 翻转。

**已提取的物理量**(`scripts/analyze_physics.py` → `data/processed/real/physics.json`):

| 量 | 结果 | 备注 |
|---|---|---|
| 满载热点 | **79.2 °C**(SoC,窗口内 (95,40)) | 无散热器自然对流,真实热点 |
| 冷却时间常数 | τ = 411 s(满载后)/ 565 s(半载后) | 差异 31%:自然对流 h 随 ΔT 变化 + 观测窗仅 ~0.5τ;如实报告 |
| 稳态判据 | 满载 12.5 min 仍 ~0.2 °C/min 爬升 | n_eff=2,作为"准稳态尾段";复测将延长至 20 min |
| 逐像素重复性 | σ 中位 0.07–0.38 °C | 后者含慢漂移,作保守噪声模型 |
| ĥ 实测 | **上界 ĥ ≲ 3**(全板暖穹顶,无远场) | 界定预训练范围;M3 源掩膜后再精化 |
| 胶带系统偏差 | +0.17 ~ +0.92 °C(33–79 °C) | 计入不确定度预算 |

**诚实性声明**(写进报告的"不确定度与局限"):单板单会话;稳态帧近似重复导致有效样本量小(n_eff=2–11);胶带点本身仍是同一台热像仪的读数(将以片上传感器日志与接触式探头打破循环论证);τ 与 ĥ 的测量局限如上表。

## 4. 应用愿景与部署演示

预训练+微调后的算子即一个**软件定义热像仪**:设备用自己的稀疏传感器实时重构全场,阈值告警/主动降频/任务迁移都可挂接。我们将在被测 Pi 4B 上实机演示:导出 TorchScript/ONNX,读取 `vcgencmd` 片上温度作为实时输入通道,基准测量重构延迟(Mac 与 Pi 双平台)。诚实框定:单个片上传感器欠定,完整 K 点版本以胶带布局结果为准,DS18B20×4 为提议的硬件扩展。
